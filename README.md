# Rock Paper Scissors

A simple browser game of Rock, Paper, Scissors built with vanilla JavaScript, HTML and CSS — no frameworks, no build step.

## Play

Open the game directly in any browser:

```
Rock-paper_scissors web game/index.html
```

Or serve the folder locally:

```bash
cd "Rock-paper_scissors web game"
python3 -m http.server 8000
# then visit http://localhost:8000
```

## How it works

- You pick rock, paper or scissors.
- The computer picks at random.
- The winner of each round is decided by the classic rules and the score updates on screen.

## Project structure

```
Rock-paper_scissors web game/
├── index.html   # markup and layout
├── styles.css   # styling
└── app.js       # game logic
```
